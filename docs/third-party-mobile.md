# 第三方模式自动发现（本地修改版）

版本：0.2.3-mobile.2；基于 yexi-by/dsh-unrestricted，保留上游许可证。

通过宿主 `agentPresets.list()` 扫描真实注册模式，状态页显示第三方名称、ID、注入状态和预览。状态刷新和重新检查会重扫；运行中新建的第三方 Agent 在首次组装时也会自动发现，无需维护模式 ID 列表。

四个内置模式继续使用原来的特征校验。第三方模式保留角色、工具协议、计划/审批和结构化输出原文，仅添加一个独立提示词分块，不假设第三方采用官方角色文案。开关关闭不改变组装结果。

0.2.3-mobile.2 修复第三方模式始终显示 checking：启用、刷新和重新检查会校验所有已扫描模式，包括尚未实际使用的第三方模式。检查和预览会临时挂载模式，可能触发模式自身的初始化代码。检查通过表示提示词兼容性检查通过，不保证模型回答效果。

特殊限制：最终仅一个分块的模式（包括 `complete: true` 完整提示词）暂不自动修改；首次使用时报告需要显式适配。动态按请求切换完整提示词的特殊实现仍需单独验证。绕过 Harness、直接请求模型 API 的插件不经过此入口。扫描成功、注入成功和模型实际回答效果是不同结论。

已在相邻 Harness 0.2.1-alpha.1 的真实宿主中验证：独立第三方 ID、运行中新增模式、自定义角色和审批规则保留、工具目录不变、关闭恢复、完整提示词保留；同时通过原有模式及子代理检查。未请求模型 API，未在 Android rc.2 上安装或验收此修改版。

安装：通过 DSHA 的插件导入入口导入本轮生成的 ZIP，重启 Web。启用插件后还需开启插件设置中的功能开关。请使用模式列表、预览和实际运行状态确认匹配结果。
